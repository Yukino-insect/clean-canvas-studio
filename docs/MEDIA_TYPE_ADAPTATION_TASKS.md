# 图片/视频媒体类型适配：配置与预览任务台账

| --- | --- | --- | --- |
| MT-01 | 将界面语言从内容修复页移至高级设置。 | 内容修复设置区不再显示语言；高级设置可修改语言。 | 已完成 |
| MT-02 | 内容修复页按选中媒体自动切换图片/视频专属配置。 | 图片时隐藏视频掩膜策略和时间轴；视频时恢复。 | 已完成 |

| MT-07 | 补充离屏回归测试与文档。 | 默认测试验证图片/视频控件可见性、视频帧预览、语言设置位置。 | 已完成 |

## 验证记录

- 内容修复：初始/图片状态隐藏视频掩膜策略和时间轴；加载视频后恢复两者。
- 增强页：图片/视频分段按钮会切换文件选择过滤和视频专属提示。
- 增强视频：选择任务后显示帧滑块；3 帧测试视频可拖到第 3 帧。
- 资源释放：切换或关闭预览会释放 `cv2.VideoCapture`，避免 Windows 占用视频文件。
