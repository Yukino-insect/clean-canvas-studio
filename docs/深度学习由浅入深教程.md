# 深度学习：由浅入深的理解与实践

> 目标：理解深度学习训练的完整因果链——**数据 → 模型 → 损失 → 梯度 → 参数更新 → 验证与迭代**。本文强调概念之间的关系与容易出错的细节；公式是帮助理解的工具，而不是需要孤立背诵的装饰。

## 开始前：给完全零基础读者的一张地图

如果你目前只知道“人工智能会学习”，甚至连 Python、函数、概率、矩阵这些词都不熟悉，也可以读这篇文章。你不需要先把所有公式背下来；本教程真正希望你先建立的是一个朴素但正确的因果关系：**计算机先看例题，再猜答案；我们用“猜错多少”告诉它哪里不好；它据此微调内部的一大串数字；重复足够多次后，再用没见过的新题检查它是否真的学会。**

以“判断一张照片里有没有猫”为例：

```text
带“有猫 / 无猫”答案的照片
            │
            ▼
       模型读取照片
            │
            ▼
   输出一个猜测：例如“有猫 80%”
            │
            ▼
  损失函数比较“猜测”与“标准答案”
            │
            ▼
  反向传播找出：模型内部哪些数字该增、哪些该减
            │
            ▼
   优化器完成一次小幅修改，然后处理下一批照片
```

这条流程就是全文的主线。后文出现的 `Tensor`、神经网络、交叉熵、梯度下降、CNN、Transformer 等词，都是为了把其中某一环做得更具体、更可靠或更适合某类数据；它们不是一堆必须按字母顺序背诵的名词。

### 先分清几件容易混在一起的事

| 名称 | 它在回答什么问题 | 生活化比喻 | 不是它的什么 |
|---|---|---|---|
| **数据（data）** | 用哪些例子教模型、用哪些例子考试？ | 习题、答案和模拟卷 | 不是模型本身 |
| **模型（model）** | 用什么规则从输入得到一个猜测？ | 学生脑中的解题方法 | 不是训练过程 |
| **训练（training）** | 怎样根据错题改进模型？ | 做题、订正、再做题 | 不是部署后的实际使用 |
| **推理（inference）** | 训练完成后，怎样处理一个新输入？ | 考试时作答 | 不会再修改参数 |
| **评估（evaluation）** | 模型究竟学得怎样，是否只是在背题？ | 用从未做过的试卷测验 | 不是让模型学习答案 |

例如，图片去噪模型的**数据**是“有噪点图片 / 干净图片”的成对样本；**模型**是一个把前者映射为后者的函数；**训练**是不断比较输出与干净图片并修改参数；用户后来拖入一张新图片并点击处理，则是**推理**。把这四件事区分开，已经避开了不少初学者会遇到的误解。

### 读本文前需要什么，不需要什么

需要的只有：会进行基本四则运算，愿意运行和修改少量 Python 代码，并接受“开始看不懂一部分公式很正常”。如果你还不会 Python，建议先掌握变量、列表、函数、`for` 循环、导入包和虚拟环境；它们是阅读 PyTorch 代码的语言基础，不是深度学习理论本身。

暂时**不需要**：线性代数证明、微积分严格推导、GPU 编程、从零手写自动求导、自己训练大语言模型，或购买显卡。本文配套的二维分类示例可以在 CPU 上运行。先把一个小闭环跑通，比收藏一长串“必学架构”实际得多。

### 阅读时反复会遇到的词：先认识，不急着精通

| 术语 | 第一次可这样理解 | 在代码里常长什么样 | 之后何时深入 |
|---|---|---|---|
| **样本（sample）** | 一道独立的练习题，如一张图片 | `x[i]` | 数据集与 batch |
| **特征（feature）** | 供模型参考的信息，如像素值、面积、年龄 | `x` 的一列或一个维度 | 张量与模型输入 |
| **标签（label）** | 人或规则给出的标准答案 | `y` | 任务类型与损失函数 |
| **参数（parameter）** | 模型训练时会被修改的内部数字 | `model.parameters()` | 线性层、梯度下降 |
| **预测（prediction）** | 模型根据输入给出的答案 | `logits`、`pred`、`y_hat` | 输出层与推理 |
| **损失（loss）** | 将“错得多不多”变成一个数字的评分规则 | `loss = criterion(...)` | 交叉熵、MSE |
| **梯度（gradient）** | 告诉每个参数应往哪个方向改、改多快的信号 | `parameter.grad` | 反向传播 |
| **优化器（optimizer）** | 按梯度真正修改参数的工具 | `optimizer.step()` | SGD、AdamW |
| **epoch** | 训练集被完整看过一遍 | 外层 `for epoch in ...` | 训练循环 |
| **batch / 批** | 一次交给模型的一小组样本 | `for x, y in loader` | 批训练 |
| **泛化（generalization）** | 在没见过的新数据上仍然表现良好 | 验证/测试指标 | 过拟合与数据划分 |

看到术语时，先问它属于上面流程的哪一环即可。比如 `loss.backward()` 名字虽然有些不近人情，但它做的只是“从错题分数倒着追溯，算出每个可修改数字该如何调整”；`optimizer.step()` 才是真正落笔改数字的那一步。

### 最小训练循环：先把每一行和地图对应起来

下面代码不要求你立刻能自己写出；先把它当作训练过程的“骨架”。后文会分别解释每一行为什么存在。

```python
for x, y in train_loader:                  # 1. 取一小批带答案的训练样本
    optimizer.zero_grad(set_to_none=True)  # 2. 清除上一题留下的修改建议
    prediction = model(x)                  # 3. 前向传播：让模型猜答案
    loss = criterion(prediction, y)        # 4. 计算这批样本猜错多少
    loss.backward()                         # 5. 反向传播：计算每个参数的修改建议
    optimizer.step()                        # 6. 优化器：按建议更新模型参数
```

其中 `x` 可以是一批图片，`y` 是对应答案；`model`、`criterion` 和 `optimizer` 分别对应模型、评分规则和改错规则。训练循环只是在重复这六步。若你此刻只能理解注释，已经足够开始；理解每一行的数学细节是接下来的学习目标。

## 概念总览：数学模型、网络模型到底在描述什么

这一节先不要求你推导公式。它的任务是解释全文出现的模型与概念分别是什么、彼此怎样连接。可以把后文看成这里的“放大版”：先知道一台机器有哪些部件，再去理解每颗螺丝的作用，顺序会自然得多。

### 1. “模型”不是一个神秘黑箱，而是一个可调函数

在机器学习中，**模型（model）**首先是一个数学函数：它接收输入 `x`，经过一套规则，给出输出 `ŷ`（读作“y hat”，表示对 `y` 的预测）。

$$
\hat y=f_\theta(x)
$$

其中：

- `x`：输入。例如房屋面积、照片像素、句子中的词，或视频中的一帧；
- `ŷ`：模型的预测。例如房价、猫的概率、下一个词；
- `f`：从输入得到输出的计算规则；
- `θ`（theta）：规则中允许训练过程调整的一组数字，统称**参数**。

所谓“学习”，不是程序凭空获得意识，而是从数据中寻找一组较合适的 `θ`，使输入与正确输出之间的对应关系尽可能被这个函数描述。不同网络模型的主要区别，就在于 `f` 的结构不同：MLP 擅长一般数值特征，CNN 假设图像有局部空间结构，RNN/LSTM 假设数据按顺序到来，Transformer 则让元素直接建立全局关系。

### 2. 最简单的数学模型：线性回归

假设要根据房屋面积 `x` 预测房价 `ŷ`。最简单的假设是“面积每增加 1 平方米，价格大致增加固定数量”，写成：

$$
\hat y=wx+b
$$

- `w` 是**权重**：面积对预测价格的影响强度；
- `b` 是**偏置**：即使面积为 0 时，模型给出的基准值；
- `w` 和 `b` 就是这个模型的参数 `θ`。

例如 `ŷ = 2x + 10` 并不是说现实房价真的如此简单，而是模型当前暂时采用的一条直线。训练数据会告诉它这条线应当向上、向下、变陡还是变平。输入不止一个数时，公式变为：

$$
\hat y=w_1x_1+w_2x_2+\cdots+w_dx_d+b
$$

这仍然是在做“每项输入乘一个权重，再相加”。矩阵写法 `$\hat y=Wx+b$` 只是把大量这样的乘加计算压缩成一个式子；它没有凭空增加新的魔法。

**线性回归**适合预测连续数值，例如价格、温度、销量或图像中某个连续物理量。它的核心假设是：输入改变带来的输出变化可以由一条直线、一个平面或更高维的平面近似。现实问题当然经常更复杂，这正是神经网络需要非线性的原因。

### 3. 从“预测数值”到“预测类别”：逻辑回归与概率

若问题改为“这封邮件是不是垃圾邮件”，答案只需要“是 / 否”。模型仍可先计算一个线性分数：

$$
z=wx+b
$$

但 `z` 可能是 `-12`、`0.7` 或 `35`，不能直接被解释为概率。于是我们用 **Sigmoid 函数**把任意实数压缩到 0 到 1：

$$
p=\sigma(z)=\frac{1}{1+e^{-z}}
$$

这里的 `p` 可理解为“模型认为正类出现的概率”。`z` 则叫作 **logit**，即尚未转换为概率的原始分数。名称略显冷淡，但本质并不复杂：logit 是模型的原始意见，Sigmoid 是把意见换算成概率刻度。

这类模型叫作**逻辑回归（logistic regression）**，尽管它解决的是分类而不是回归。二分类时通常按阈值作决定，例如 `p ≥ 0.5` 判为正类；业务上若漏检代价很高，也可以改用更低阈值。多分类问题（猫、狗、鸟三选一）会输出多个 logit，再用 **Softmax** 变为总和为 1 的多类别概率。多标签问题（图片中是否同时有猫、狗、树）则对每个标签分别使用 Sigmoid，因为多个答案可以同时为真。

### 4. 损失函数：把“猜得不好”变成可比较的分数

模型不能只听到“这次错了”，还需要一个连续的数字来表示错得有多严重，才能判断下一次修改是否有帮助。这个评分规则就是**损失函数（loss function）**。

回归常用均方误差：

$$
MSE=\frac{1}{N}\sum_{i=1}^{N}(y_i-\hat y_i)^2
$$

它逐个计算“预测值与真实值的差”，平方后求平均。平方的作用是让正负误差不会互相抵消，并更严厉地处罚大错。

分类常用交叉熵。若正确答案是“猫”，模型给“猫”的概率是 0.99，损失很小；若它非常自信地只给 0.001，损失就很大。交叉熵因此不是“算准确率的另一种写法”，而是一种在训练时更适合提供修改方向的评分方式。**Accuracy、Precision、Recall、F1 是评估指标；交叉熵、MSE、BCE 是训练时用来产生梯度的损失。** 两者都衡量好坏，但职责不同，不能随意互换。

对全体训练样本取平均损失，得到训练真正试图最小化的目标：

$$
\mathcal{L}(\theta)=\frac1N\sum_{i=1}^{N}\ell(f_\theta(x_i),y_i)
$$

这里小写 `ℓ` 是单个样本的损失，大写 `L` 或 `$\mathcal{L}$` 是整批或整个数据集的平均损失。看起来只是符号差别，含义却不同；这类细节在代码报错时往往比模型名字更有用。

### 5. 梯度下降与反向传播：模型怎样“知道该改哪里”

参数可能有几十个、几百万个甚至更多。训练不可能靠随机猜测“把第 417 个数字加一点会不会更好”。**梯度（gradient）**提供了局部、定量的答案：对每一个参数，损失若想增大得最快该朝哪边变化；所以想减小损失，就沿反方向走一小步。

$$
\theta \leftarrow \theta-\eta\nabla_\theta\mathcal{L}
$$

- `$\nabla_\theta\mathcal{L}$`：损失对所有参数的梯度；
- `η`（eta）：**学习率**，决定每次迈多大步；
- 左箭头表示“把旧参数替换为更新后的新参数”。

可以把它想成在起伏地形中下山：梯度告诉你当前位置上坡最快的方向，反方向通常是最陡的下坡方向。学习率太大像一步跨过山谷，可能在两侧反复震荡甚至掉进数值溢出的坑里；太小则像每次只挪一粒沙，训练会非常慢。

神经网络由许多层函数串联：输入经过第一层、激活函数、第二层，最后才得到损失。**反向传播（backpropagation）**利用链式法则，从最终损失倒着计算“每一层参数对总错误贡献了多少”。它不是另一种优化算法，而是高效计算梯度的方法；**优化器**才是使用梯度更新参数的规则。PyTorch 的 `loss.backward()` 负责前者，`optimizer.step()` 负责后者。把两者混为一谈是常见误会，倒也情有可原，毕竟名字确实没有主动替人解释自己。

### 6. 神经网络：在线性模型之间加入非线性

一个线性层计算 `$z=Wx+b$`。如果连续叠加两层、但中间什么也不做：

$$
W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)
$$

结果仍然等价于一层线性变换；层数增加了，能描述的边界却没有真正变复杂。因此神经网络会在层之间插入**激活函数（activation function）**，例如 ReLU：

$$
ReLU(z)=max(0,z)
$$

一个最常见的多层感知机可写成：

$$
h_1=ReLU(W_1x+b_1),\qquad \hat y=W_2h_1+b_2
$$

`h₁` 称为**隐藏表示**或**隐藏层特征**。不要把“神经元”理解为软件中真实存在的小脑细胞：在基础神经网络里，一个神经元通常只是“一组权重、一次加权求和、一个偏置，再经过激活函数”的计算单元。大量单元并行，才让模型能够把简单特征组合成复杂模式。

神经网络比线性模型强，是因为非线性激活让它能表示弯曲、分段或高度复杂的输入—输出关系；并不因为“层数多”本身具有神力。更多层和更多参数也会带来更高的数据需求、计算成本和过拟合风险。

### 7. 网络模型不是等级榜，而是对数据结构的不同假设

| 网络模型 | 它假设数据有什么结构 | 核心计算 | 典型输入 | 初学时先记住什么 |
|---|---|---|---|---|
| **MLP / 全连接网络** | 每个特征只是一个数，位置和顺序不重要 | 线性层 + 激活函数 | 表格、已提取特征、教学玩具数据 | 是理解训练闭环的最好起点 |
| **CNN / 卷积神经网络** | 相邻像素通常相关；同一种局部模式可能出现在不同位置 | 小卷积核滑动并共享参数 | 图片、视频帧、二维信号 | 擅长局部纹理、边缘与空间结构 |
| **RNN / LSTM / GRU** | 数据按时间或词序排列，当前应参考过去 | 隐藏状态逐步传递 | 时间序列、早期文本/语音 | 自然处理顺序，但长序列难并行 |
| **Transformer** | 序列中任意两个位置可能直接相关 | 注意力机制比较并聚合各位置 | 文本、图像块、音频、多模态 | 强于长程关系与并行计算，但注意力成本高 |

它们并非“CNN 低级、Transformer 高级”的升级关系。若把商品表格数据硬塞进图像 CNN，或用复杂 Transformer 处理几十个规整数值特征，通常只会增加成本与排错难度。应先观察数据的结构，再选与之匹配的归纳偏置。

#### 7.1 MLP：把特征整体送入多层变换

**多层感知机（MLP）**将一个样本表示为向量，例如 `[年龄, 收入, 浏览次数, 是否会员]`。每一层都让所有输入特征与所有输出单元相连，所以也叫全连接层。它不知道“第 1 个数字和第 2 个数字在空间上相邻”意味着什么；这正是表格数据中往往无妨、图像数据中却很浪费的地方。

MLP 是本教程配套二分类示例采用的模型。它足够简单，因而你可以把注意力放在数据、损失和训练循环上，而不用同时处理卷积、序列掩码或多头注意力。

#### 7.2 CNN：让模型用同一个小观察窗扫描图像

**卷积核（kernel / filter）**可以理解为一个小型权重矩阵，例如 `3×3`。它覆盖图像的一小块区域，做加权求和得到一个输出；然后向右、向下滑动，重复使用同一组权重。若某个卷积核学会检测“横向边缘”，它就能在图像任何位置检测横向边缘，不必为左上角和右下角各准备一套参数。

卷积产生的结果称为**特征图（feature map）**。浅层卷积常响应于边缘、颜色变化或简单纹理；更深层会组合成角点、形状、部件乃至对象语义。这是对典型图像统计规律的合理假设，不是不可违背的自然定律。`stride` 决定卷积核每次移动多远，`padding` 决定边缘是否补零，池化或带步长卷积常用于降低分辨率、扩大感受野。

**残差连接（residual connection）**将输入直接加到经过若干层的结果上：`F(x) + x`。它给深层网络保留了一条更直接的信息与梯度通路，是 ResNet 能稳定训练得很深的重要原因。

#### 7.3 RNN、LSTM 与 GRU：把过去压缩进状态

对一句话或温度序列，顺序通常重要。**循环神经网络（RNN）**在处理第 `t` 个元素时，会同时读取当前输入 `x_t` 与上一步状态 `h_(t-1)`，产生新状态 `h_t`。这个状态可被理解为“截至目前的压缩记忆”。

普通 RNN 在很长序列上容易出现**梯度消失**或**梯度爆炸**：反向传播时许多小于 1 或大于 1 的因子连续相乘，早期信息的训练信号会趋近于 0 或变得极大。**LSTM** 和 **GRU** 用门控机制决定信息保留、写入和遗忘的比例，从而缓解长期依赖问题。它们并没有真的像人一样“记忆”，而是在数值上提供了更容易保持信息与梯度的路径。

即使 LSTM 改善了长期依赖，RNN 系列仍通常必须按 `t=1, 2, 3...` 顺序计算，难以充分并行。这也是 Transformer 在大量序列任务中逐渐成为主流的工程原因之一。

#### 7.4 Transformer：让每个位置主动参考相关位置

**注意力（attention）**的朴素问题是：“处理当前位置时，序列中的其他位置哪些值得参考，各参考多少？”Transformer 会把每个 token（词、图像块等）映射为三组向量：

- **Query（Q）**：当前位置正在寻找什么；
- **Key（K）**：每个位置提供什么索引线索；
- **Value（V）**：每个位置实际可被取用的内容。

用 Q 与所有 K 的相似度得到权重，再对 V 加权求和，便得到当前位置融合上下文后的表示：

$$
Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

例如理解“它很甜”中的“它”，模型可以让“它”更多关注前文可能的名词，而不是只依赖紧邻的一个词。**多头注意力**则让多组较小的 Q/K/V 并行学习不同关系：某个头可能偏向位置关系，另一个可能偏向语义相似性。

Transformer 还需要**位置编码**，因为注意力本身并不知道词的先后顺序；需要残差连接与 LayerNorm 来稳定深层训练；在自回归文本生成中，还需要**因果掩码**禁止当前位置偷看未来词。注意力能全局建模，但标准实现会比较大量位置对，序列很长时计算和显存成本大致随长度平方增长。

### 8. 训练概念：参数、超参数、批次与优化器

这几个词很像，却属于不同层级：

| 概念 | 谁来决定或修改 | 例子 | 它解决什么 |
|---|---|---|---|
| **参数（parameter）** | 训练过程自动学习 | 权重 `W`、偏置 `b` | 模型具体应怎样计算 |
| **超参数（hyperparameter）** | 人或实验策略设置 | 学习率、batch size、层数、权重衰减 | 学习过程和模型容量如何安排 |
| **batch** | 数据加载器划分 | 一次送入 32 张图片 | 控制一次更新用多少样本、占多少内存 |
| **epoch** | 训练循环计数 | 完整遍历训练集 10 次 | 衡量训练进行了多少轮 |
| **优化器** | 人选择、代码执行 | SGD、Adam、AdamW | 如何根据梯度更新参数 |

一个 epoch 不等于一次参数更新。若有 3,200 个样本、batch size 为 32，那么一个 epoch 大约有 100 次 `optimizer.step()`。**SGD** 可理解为按当前 batch 的梯度直接走一步；**Momentum** 会参考过去的更新方向；**Adam/AdamW** 会为不同参数自适应调整步长。它们都在执行“利用梯度减小损失”这一共同目标，只是走法不同。

### 9. 泛化、过拟合与正则化：学会规律，不是背答案

若模型在训练数据上很准确、换一批没见过的数据就表现很差，称为**过拟合（overfitting）**。这像学生记住了练习题的答案，却没有理解题型。相反，训练集本身都做不好，通常是**欠拟合（underfitting）**：模型能力不足、训练不够、学习率不合适，或数据/标签/代码有错误。

因此数据通常分为：

- **训练集**：用于更新参数；
- **验证集**：用于选择模型、超参数和停止时机；
- **测试集**：最后一次、尽量客观地报告泛化能力。

**正则化（regularization）**泛指减少模型死记硬背倾向的方法，例如权重衰减（限制权重过大）、Dropout（训练时随机暂时屏蔽部分特征）、数据增强（改变训练样本外观但不改变标签）和早停（验证表现不再改善时停止）。它们不是任何任务都该无脑叠满的“性能按钮”；当模型本来就没学会训练集时，过强正则化只会让问题更加明显。

### 10. 预训练、迁移学习与微调：为什么不总是从零训练

深度网络往往需要大量数据才能从随机参数中学到有用表示。**预训练（pretraining）**是在大规模通用数据上先训练模型；**迁移学习（transfer learning）**是在新任务中复用这些已学到的表示；**微调（fine-tuning）**则是在新数据上继续训练全部或部分参数。

例如，一个在大量通用图片上学会边缘、纹理和物体轮廓的视觉模型，迁移到“识别工业零件缺陷”时，不必从“什么是边缘”重新开始。小数据任务常会先冻结大部分预训练网络，只训练最后的任务头；数据充足、领域差异较大时再逐步解冻更多层。LoRA 等参数高效微调方法只训练少量新增参数，目的是减少显存与存储开销。

预训练能降低起点，却不能修复错误标签、数据泄漏、失真的评估指标或不匹配的任务定义。模型越强，越可能迅速把错误流程包装成看似不错的数字；这一点并没有因为名字更时髦而变得例外。

## 0. 数学预备知识：读懂公式所需的最小基础

深度学习不要求一开始就掌握严密的数学证明，但以下概念必须有直觉。后文每次使用它们时，都会回到其在模型中的实际意义；不必因为公式稍多就急着绕开它们，毕竟代码所做的事并不会因此变得更简单。

### 0.1 本文的 LaTeX 书写约定

- 行内公式使用单个美元符号，例如 `$x \in \mathbb{R}^d$`；
- 单独成行的公式使用双美元符号，例如：

$$
y = wx + b
$$

其中 `x` 是输入，`w` 是权重，`b` 是偏置，`y` 是输出。下文所有数学公式均遵循这一约定，以便 Markdown 渲染器正确显示。

### 0.2 标量、向量、矩阵与张量

- **标量（scalar）**：一个数，如温度 $25.0$；通常用小写斜体 $x$、$b$ 表示。
- **向量（vector）**：有顺序的一组数，如一个样本的多个特征。$x \in \mathbb{R}^d$ 表示 $x$ 有 $d$ 个实数特征。
- **矩阵（matrix）**：二维数表，如一个 batch 的样本，或线性层的权重。$W \in \mathbb{R}^{m \times n}$ 表示 $W$ 有 $m$ 行、$n$ 列。
- **张量（tensor）**：任意维数组，是 PyTorch 的基本数据对象。标量、向量、矩阵可分别看作 0、1、2 维张量。

维度必须匹配。若 $x \in \mathbb{R}^n$，且 $W \in \mathbb{R}^{m \times n}$，则：

$$
Wx \in \mathbb{R}^m
$$

这正是 `nn.Linear(in_features=n, out_features=m)` 的数学含义。形状报错并非框架故意为难你；它在指出这个乘法没有定义。

### 0.3 点积、矩阵乘法与转置

两个同长度向量的点积是逐元素相乘后求和：

$$
a^T b = \sum_{i=1}^{d} a_i b_i
$$

点积可衡量两个向量的匹配程度。线性层中的一个输出神经元，本质上就是“输入向量与一组权重做点积，再加偏置”。

上标 $T$ 表示**转置**，即交换矩阵的行和列。一个 batch 的输入若写作 $X \in \mathbb{R}^{B \times n}$，PyTorch 的线性层可等价表示为：

$$
Z = XW^T + b
$$

其中 $B$ 是 batch size，$W \in \mathbb{R}^{m \times n}$，输出 $Z \in \mathbb{R}^{B \times m}$；偏置 $b$ 会自动广播到每一行。

### 0.4 求和、均值、方差与标准化

$\sum$ 表示求和，$\frac{1}{N}\sum_{i=1}^N x_i$ 是 $N$ 个数的均值：

$$
\mu = \frac{1}{N}\sum_{i=1}^{N}x_i
$$

方差衡量数据围绕均值的离散程度，标准差是方差的平方根：

$$
\sigma^2 = \frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2, \qquad \sigma = \sqrt{\sigma^2}
$$

标准化常写为：

$$
x' = \frac{x-\mu}{\sigma+\epsilon}
$$

它会将特征平移到接近 0、缩放到相近尺度，令优化器不必同时处理“面积是数百、房龄是个位数”之类尺度悬殊的输入。$\epsilon$ 是很小的正数，用于避免除以 0。训练项目中，$\mu$ 与 $\sigma$ 必须只由训练集计算，原因会在“数据泄漏”部分说明。

### 0.5 导数、偏导数、梯度与链式法则

导数描述一个变量变化时函数变化的快慢。例如 $y=x^2$ 的导数是 $\frac{dy}{dx}=2x$。多参数函数中，固定其他变量、只考察某一变量的变化率，称为**偏导数**：$\frac{\partial L}{\partial w}$。

将损失 $L$ 对所有参数的偏导数排成向量，得到**梯度**：

$$
\nabla_\theta L = \left[\frac{\partial L}{\partial \theta_1}, \frac{\partial L}{\partial \theta_2}, \ldots\right]
$$

梯度指向损失上升最快的方向，因此优化时走反方向。神经网络是层层复合函数，链式法则让误差能从输出层传回前面的参数：

$$
\frac{dL}{dx} = \frac{dL}{dy} \cdot \frac{dy}{dx}
$$

这就是反向传播的数学核心。PyTorch 会替你算导数，但不会检查你是否把错误的标签或错误的损失函数塞进了图中；这一点仍需要人来负责。

### 0.6 概率、条件概率与分类概率

概率 $P(A)$ 介于 0 与 1。$P(y=1 \mid x)$ 表示“在已知输入 $x$ 时，标签为正类的概率”。二分类模型通常先输出任意实数 logit $z$，再用 Sigmoid 转为概率：

$$
P(y=1 \mid x) = \sigma(z) = \frac{1}{1 + e^{-z}}
$$

多分类中，各类别概率应非负且和为 1；Softmax 正是完成这一归一化的函数。交叉熵则衡量预测概率分布与真实标签之间的差异。这些概念将在损失函数一节中结合代码说明。

## 1. 全局框架：模型在学习什么

深度学习把任务表示为一个带参数的函数：

$$
\hat y=f_\theta(x)
$$

- `x` 是输入，例如特征向量、图片、文本或音频；
- `y` 是真实答案（标签）；
- `ŷ` 是预测；
- `θ` 是网络的可学习参数，包括权重和偏置。

训练不是让模型“记住答案”，而是在训练样本上寻找一组参数，使损失函数尽可能小：

$$
\theta^*=\arg\min_\theta \frac1N\sum_{i=1}^{N}\mathcal L(f_\theta(x_i),y_i)
$$

一轮训练中的关键步骤如下：

1. **前向传播**：输入 `x` 经模型得到预测 `ŷ`。
2. **计算损失**：用 `L(ŷ, y)` 将预测误差转换为可优化的标量。
3. **反向传播**：依据链式法则计算每个参数的梯度 `∂L/∂θ`。
4. **优化器更新**：沿梯度的反方向更新参数。
5. **验证泛化性**：在没有参与梯度更新的数据上评估模型。

其中任一环节定义错误，模型即使“在运行”，也未必在学习你真正想要的东西。训练日志看起来很热闹并不能证明这一点。

## 2. 任务、输出层、标签与损失函数必须配套

先识别任务类型，再确定模型输出、标签格式与损失。这个对应关系是最常见也最基础的错误来源。

| 任务 | 模型最后输出 | 标签格式 | 推荐损失 | 推理方式 |
|---|---|---|---|---|
| 回归 | 一个或多个连续数值 | `float` 连续值 | `MSELoss`、`L1Loss`、Huber | 直接使用输出 |
| 二分类 | 一个 **logit** | `float` 的 0/1，形状与输出一致 | `BCEWithLogitsLoss` | `sigmoid(logit)` 后按阈值判断 |
| 单标签多分类 | `C` 个 logits | `long` 类别索引 `[0, C-1]` | `CrossEntropyLoss` | `argmax(logits, dim=1)` |
| 多标签分类 | 每个标签一个 logit | 多热向量，通常为 `float` | `BCEWithLogitsLoss` | 每个维度独立 sigmoid、阈值判断 |

### 2.1 Logit、Sigmoid 与 Softmax

**logit** 是激活函数之前的原始分数，范围是整个实数轴。二分类中：
$$
p=\sigma(z)=\frac{1}{1+e^{-z}}
$$

`p` 才是类别为正的概率。多分类中，Softmax 将各类别 logit 归一化为和为 1 的概率：
$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

PyTorch 的 `BCEWithLogitsLoss` 内置 Sigmoid，`CrossEntropyLoss` 内置 LogSoftmax。因此训练时应直接传入 **logits**，不要手动再接 Sigmoid 或 Softmax。这么做既避免重复变换，也能获得更稳定的数值计算。

```python
# 正确：二分类
logits = model(x)                         # [B, 1]
loss = nn.BCEWithLogitsLoss()(logits, y)  # y 也应为 [B, 1]，float

# 正确：十分类
logits = model(x)                         # [B, 10]
loss = nn.CrossEntropyLoss()(logits, y)   # y 为 [B]，long，值在 0 到 9
```

## 3. 张量、线性层与非线性

张量（Tensor）就是多维数组。常见形状约定：

| 数据 | 常见形状 | 含义 |
|---|---|---|
| 一批表格数据 | `[B, D]` | B 个样本、每个样本 D 个特征 |
| 一批图像（PyTorch） | `[B, C, H, W]` | 批量、通道、高、宽 |
| 一批 token 特征 | `[B, L, D]` | 批量、序列长度、隐藏维度 |

线性层执行仿射变换：

$$
z=Wx+b
$$

若连续堆叠纯线性层，它们仍可合并成一个线性变换，表达能力不会实质增加。因此网络必须插入激活函数：

$$
h=\phi(Wx+b)
$$

- `ReLU(x)=max(0,x)`：基础 CNN、MLP 的可靠默认选择；
- LeakyReLU：保留负区间的小梯度，缓解死亡 ReLU；
- GELU/SiLU：更平滑，现代 Transformer 与视觉模型中常见；
- Sigmoid：主要用于把二分类 logit 转换为概率，而非深层隐藏层的首选。

多层感知机（MLP）通过“线性层 + 非线性层”的重复组合，便可拟合非线性边界：

```python
nn.Sequential(
    nn.Linear(input_dim, 32),
    nn.ReLU(),
    nn.Linear(32, 16),
    nn.ReLU(),
    nn.Linear(16, 1),  # 二分类：输出一个 logit，不要在这里写 Sigmoid
)
```

## 4. 损失、梯度与反向传播

### 4.1 常见损失的直觉

回归中的均方误差：

$$
MSE=\frac1N\sum_i(y_i-\hat y_i)^2
$$

它会更严厉地惩罚大误差，因此对异常值敏感。MAE（绝对误差）更稳健；Huber Loss 则在小误差时像 MSE、大误差时像 MAE。

分类中的交叉熵会重罚“自信但错误”的预测。对真实类别 `y`，多分类交叉熵是：

$$
L=-\log p_y
$$

若真实标签是猫，模型赋予猫 0.99 概率，损失很小；若只给 0.001 概率，损失很大。这正符合分类任务的目标。

### 4.2 梯度下降

梯度 `∇θL` 表示损失上升最快的方向，因此参数使用其反方向更新：

$$
\theta \leftarrow \theta-\eta\nabla_\theta L
$$

`η` 是学习率。它是最敏感的超参数之一：

- 太小：损失下降缓慢，训练看似没有进展；
- 太大：损失震荡、发散，甚至出现 `NaN`；
- 合适：训练损失整体下降，验证指标在一段时间内改善。

反向传播通过链式法则从损失向前逐层计算梯度。框架会自动完成它，但并不免除理解责任：你仍需保证前向图、损失、标签和参数更新是正确的。

```python
optimizer.zero_grad(set_to_none=True)  # 清除上一个 batch 的梯度
logits = model(x)                       # 前向传播
loss = criterion(logits, y)             # 损失
loss.backward()                         # 计算参数梯度
optimizer.step()                        # 用梯度更新参数
```

PyTorch 默认累积梯度；忘记 `zero_grad` 会使本不应累积的梯度相加。除非你正在有意做梯度累积，否则这通常是错误。

## 5. 优化器、批训练与训练稳定性

实际训练以 mini-batch 为单位。若训练集有 `N` 个样本、批大小为 `B`，每个 epoch 的更新步数约为 `ceil(N/B)`。小批量既能利用 GPU 并行，又引入一定梯度噪声，通常比逐样本或全量更新更实用。

常见优化器：

- **SGD**：简单、可控，充分调参后在视觉任务上常有良好泛化；
- **SGD + Momentum**：利用历史更新方向平滑震荡、加速收敛；
- **Adam**：对不同参数自适应设置更新尺度，易于起步；
- **AdamW**：将权重衰减与 Adam 更新解耦，是现代任务常用默认值。

```python
optimizer = torch.optim.AdamW(
    model.parameters(), lr=3e-3, weight_decay=1e-4
)
```

`weight_decay` 是正则化手段，会抑制过大的权重；它不是性能提升的魔法开关。对于很小的模型或已欠拟合的数据，过强正则化只会让学习更困难。

学习率调度常在后期降低步长以细化收敛：Step Decay、Cosine Decay、验证指标停滞时衰减（`ReduceLROnPlateau`）都很常见。大型 Transformer 训练常组合 warmup 与余弦衰减。

## 6. 数据划分与泛化：比模型堆叠更优先

数据应划分为：

- **训练集**：参与梯度更新；
- **验证集**：选择超参数、epoch、阈值和模型版本；
- **测试集**：只在最后评估一次，以估计真实泛化能力。

测试集不能反复用于调参。每次根据测试分数修改模型，测试集就在事实上变成验证集，最终报告的测试性能也会偏乐观。

### 6.1 数据泄漏

数据泄漏指训练阶段得到本不应知道的信息。常见情况包括：

1. 在划分数据之前，用全体样本计算标准化均值和标准差；
2. 同一用户、同一患者或同一视频的相邻帧被拆到训练和测试两边；
3. 时间序列随机切分，使模型在训练时见到“未来”；
4. 标签或标签代理变量直接混入输入。

正确的标准化流程是：只用训练集计算统计量，再将同一组统计量应用到验证与测试集。

$$
x'=\frac{x-\mu_{train}}{\sigma_{train}+\epsilon}
$$

### 6.2 欠拟合与过拟合

| 现象 | 常见表现 | 常见方向 |
|---|---|---|
| 欠拟合 | 训练集和验证集都差 | 训练更久、检查学习率、增加模型表达能力、减少过强正则化 |
| 过拟合 | 训练集很好，验证集明显变差 | 增加数据/增强、权重衰减、Dropout、早停、减小模型 |

最强的基础排错手段是：**让模型尝试过拟合几十个样本**。如果它连这个小子集都学不到接近 100% 的训练准确率，应优先检查标签、损失、输出形状、优化器调用和数据预处理，而不是立即寻找更复杂的模型。

## 7. 指标：Accuracy 从来不是全部

二分类混淆矩阵由 TP、TN、FP、FN 组成：

| 实际 / 预测 | 正类 | 负类 |
|---|---:|---:|
| 正类 | TP | FN |
| 负类 | FP | TN |

$$
Precision=\frac{TP}{TP+FP},\qquad Recall=\frac{TP}{TP+FN}
$$

$$
F1=2\cdot\frac{Precision\cdot Recall}{Precision+Recall}
$$

- Precision 高：被判为正类的样本大多正确，误报少；
- Recall 高：真实正类大多被找到，漏报少；
- F1：在两者间取平衡。

类别极不均衡时，Accuracy 可能误导。例如 99% 样本为负类时，“永远预测负类”也有 99% Accuracy，但对正类毫无作用。此时更应关注 PR-AUC、Recall、F1，或在业务阈值下的误报/漏报成本。

## 8. 主要网络结构及其归纳偏置

模型架构体现了对数据结构的先验假设，称为归纳偏置。

### 8.1 MLP：向量与表格数据的起点

MLP 将输入视为无空间、无顺序的特征向量。它适合表格和已提取特征，也适合用来理解训练闭环；本文配套项目即采用 MLP 完成二维非线性二分类。

### 8.2 CNN：利用图像的局部结构

图像临近像素具有强相关性。卷积核在空间上滑动并共享权重，因此参数量远小于把图像完全展平后接全连接层的做法。浅层常学习边缘纹理，深层逐渐编码部件与语义。

卷积输出尺寸（单维）为：

$$
\left\lfloor\frac{N+2P-D(K-1)-1}{S}+1\right\rfloor
$$

其中 `N/P/D/K/S` 分别是输入尺寸、padding、dilation、卷积核大小和 stride。ResNet 通过残差连接 `F(x)+x` 让信息和梯度更容易跨越深层，是训练深网络的关键设计。

### 8.3 RNN/LSTM：递归处理顺序

RNN 的隐藏状态将上一时刻信息带到下一时刻：

$$
h_t=\phi(W_xx_t+W_hh_{t-1}+b)
$$

但长序列反向传播易出现梯度消失或爆炸。LSTM/GRU 使用门控机制缓解问题，但因时间步串行，训练并行度有限。

### 8.4 Transformer：用注意力建立关系

Scaled Dot-Product Attention：

$$
Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

Query 表示当前需要查询什么，Key 表示每个位置可被匹配的索引，Value 是被聚合的内容。Self-Attention 使每个 token 能直接关注其他 token；多头注意力让模型从多个子空间学习关系。Transformer 还依赖：

- 位置编码：提供顺序信息；
- 残差连接：稳定深层信息流；
- LayerNorm：稳定特征尺度；
- 前馈 MLP：对每个 token 做非线性变换；
- 因果掩码：生成任务中禁止偷看未来 token。

完整注意力矩阵对长度 `L` 的时间和空间复杂度通常与 `L²` 相关，这也是长上下文模型必须关注效率的原因。

## 9. 预训练与微调

从头训练大模型需要大量数据与算力。现实项目通常从预训练模型开始：

1. **冻结主干、训练任务头（Linear Probing）**：成本低，适合小数据起步；
2. **全量微调（Full Fine-tuning）**：适应性强，学习率通常远小于从头训练；
3. **参数高效微调（如 LoRA）**：冻结大部分权重，只学习少量低秩增量，节省显存和存储。

预训练并不能替代数据审查。若下游数据定义错误、分布偏移严重或评估存在泄漏，强大的预训练模型只会更有效地掩盖问题。

## 10. 可靠训练循环与工程细节

```python
model.train()                    # 启用 Dropout，BatchNorm 使用 batch 统计量
for x, y in train_loader:
    optimizer.zero_grad(set_to_none=True)
    logits = model(x)
    loss = criterion(logits, y)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    optimizer.step()

model.eval()                     # 关闭 Dropout，BatchNorm 使用运行统计量
with torch.no_grad():            # 验证与推理不构建计算图
    logits = model(x_val)
```

训练模式与评估模式不能混用。忘记 `model.eval()` 会使 Dropout 继续随机丢弃特征，并使 BatchNorm 使用验证 batch 的统计量，最终让评估结果不稳定或失真。

建议每次实验记录：数据版本与切分方式、随机种子、模型配置、学习率、批大小、训练曲线、最佳验证指标、checkpoint 和代码版本。随机种子能提高可重复性，但不同硬件、框架版本与并行算子不一定产生逐位相同结果；工程目标应是结果和流程可追溯，而非迷信单次数字。

## 11. 常见故障的诊断顺序

### Loss 不下降

1. 先过拟合极小数据集；
2. 核对输入/标签是否一一对应；
3. 打印 tensor 的 shape、dtype、标签最小/最大值；
4. 确认损失函数、输出层和标签格式配套；
5. 确认执行了 `zero_grad`、`backward`、`step`；
6. 检查学习率是否过大或过小；
7. 检查模型参数是否真的参与梯度计算。

### 出现 NaN/Inf

检查原始输入是否含 NaN/Inf，降低学习率，检查标准化除数，改用数值稳定的 `*WithLogitsLoss`，必要时启用梯度裁剪。混合精度训练中还应检查缩放与硬件支持。

### 训练好、验证差

先确认不存在切分错误、数据泄漏、训练/验证预处理差异以及遗漏 `model.eval()`。确认后再考虑数据增强、早停、正则化、模型规模和迁移学习。不要把所有泛化问题粗暴归结为“Dropout 不够”。

## 12. 推荐的实践路线

1. 用 NumPy/PyTorch 实现线性回归和逻辑回归；
2. 完成一个 MLP 二分类闭环：划分、标准化、训练、验证、保存、加载推理；
3. 使用 CNN 完成 CIFAR-10 或自有图片分类；
4. 使用预训练 ResNet 做迁移学习，并分析错误样本；
5. 学习 Attention、Transformer 和预训练语言模型微调；
6. 再进入混合精度、分布式训练、参数高效微调、生成模型与部署。

本仓库的配套示例位于 [`examples/deep_learning_binary_classifier/`](../examples/deep_learning_binary_classifier/README.md)。它采用不需要下载的合成二维环形数据，故意选择线性模型无法完美处理的非线性边界，以最小成本呈现 MLP 为什么需要激活函数、如何避免标准化泄漏、如何评估并保存最佳模型。

## 13. 最后的检查清单

- 任务定义、成功指标和错误代价是否明确？
- 标签是否正确，训练/验证/测试切分是否符合业务边界？
- 标准化统计量是否只来自训练集？
- 模型输出、标签 dtype/shape、损失函数是否匹配？
- 模型能否过拟合一个小样本集？
- 训练时是否 `model.train()`，验证时是否 `model.eval()` 与 `no_grad()`？
- 是否保存了验证集最优 checkpoint，而不是仅保存最后一轮？
- 是否查看了错误样本，而不只是盯着单一分数？

能够逐项回答这些问题，通常比记住更多网络名词更能说明你真正掌握了深度学习。
