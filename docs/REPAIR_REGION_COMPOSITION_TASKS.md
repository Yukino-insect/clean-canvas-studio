# 修复区域组合与动态 OCR 精细定位：实施清单

本文是本次改造的验收记录。状态会随实现和验证更新；它描述的是当前仓库的目标行为，
而不是一份脱离代码的愿望清单。

## 目标与约束

- [x] 动态 OCR 可选地在 OCR 多边形内按字幕前景/背景颜色提取更小的像素掩膜。
- [x] 默认关闭精细定位；默认字幕前景为白色，提供可调整的背景参考色与描边扩张。
- [x] 将“最终掩膜来源”改名为“修复区域编辑方式”，避免误导用户以为只能选择一种来源。
- [x] 矩形、涂鸦、颜色筛选分别维护预选状态；确认仅提交当前编辑方式的区域。
- [x] 已确认的各方式在同一个 `MaskPlan` 中组合；任务启动时冻结完整计划及其颜色/扩边参数。
- [x] 颜色筛选必须先画 ROI，并在确认前显示橙色临时 mask；确认后合并结果以红色显示。
- [x] “打开 / 运行”保留为全局操作；模式专属操作放入独立的“修复区域编辑”区域。
- [x] 文档与高级设置帮助说明模式边界、动态 OCR 精细定位和精度参数。
- [x] 关键数据模型、组合逻辑和 UI 状态迁移具备注释，并完成无网络回归验证。

## 验收路径

1. 在“手工矩形”确认一个区域，切到“手工涂鸦”确认笔迹，再切到“颜色筛选”确认 ROI；红色预览应为三者并集。
2. 切换编辑方式时，当前方式未确认的预选内容和已确认来源均不丢失；涂鸦模式不显示/不编辑矩形框。
3. 在颜色筛选模式画 ROI，调整前景、背景和容差；橙色预览实时变化，确认后变为红色并并入计划。
4. 视频启用动态 OCR 后，开启“字幕像素精细定位”时，动态掩膜只保留 OCR 区域内接近字幕前景的像素，并按小扩边覆盖黑色描边；关闭时保持原 OCR 多边形路径。
5. 运行前后确认子进程得到的是序列化的组合 `MaskPlan`，而不是随后在界面上更改的配置。
