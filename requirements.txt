# Compatibility entry point for the platform-independent runtime dependencies.
#
# AI modes require a separately selected, locked PyTorch profile because a CPU
# wheel and a CUDA wheel are different binary distributions. On Windows use:
#   .\scripts\install-runtime.ps1 -TorchBackend cpu
# or
#   .\scripts\install-runtime.ps1 -TorchBackend cu126
#
# `pip install -r requirements.txt` intentionally installs only the base profile;
# OpenCV mode works, while AI modes will report that PyTorch is missing.
-r requirements/base.lock
