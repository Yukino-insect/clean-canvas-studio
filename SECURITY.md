# Security policy

## Supported versions

Security fixes are applied to the current development version of CleanCanvas
Studio.

## Reporting a vulnerability

Do not publish exploit details, malicious media samples or credentials in a
public issue before maintainers can assess the report. Use a private security
advisory when the hosting service provides one; otherwise open a minimal issue
requesting a private contact channel without exploit details.

Include the affected version, operating system, installation method, impact,
reproduction steps and whether the issue concerns model download, media parsing,
FFmpeg, path handling, dependencies or GUI task execution.

Keep FFmpeg, OpenCV, PaddlePaddle, PaddleOCR, PyTorch and the operating system
patched because the project processes untrusted image and video files.
